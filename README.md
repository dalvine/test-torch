# Тестовый проект для invest

## Проверка и запуск проекта

```
    npm i
    npm run build
    npm run start
```

## Этапы разработки

### 1. Подготовка проекта

- установка Next.js + ts
- устанвока необходимых для работы зависимостей
- настройка конфигурационных файлов

_Комментарий_: по тех. заданию был установлен Next.js, модуль tailwaind. Для строгой типизации Next.js был установлен с поддержкой type-script. Для style guide установлены и настроены eslint, prettier.

`Затраченное время: ~ 1 час`

### 2. Добавление Header

- Добавлен логотип
- Добавлено навигационное меню
- Добавлены кнопки "Signin" и "Get started"

_Комментарий_: по тех. заданию проект должен быть с отзывчивым дизайном (адаптироваться под размер). Во всем проекте используется подход desktop to mobile. Логотип был вырезан с макета, т.к. обычно логотип предоставляется. Не стал его делать с прозрачным фоном через фотошоп. Надеюсь это не критично. Остальные логотипы для соответствия макету также вырежу из макета.

`Затраченное время: ~ 2.5 часа`

### 3. Добавление приветственного раздела (Greeting)

- Добавлена вводная информация
- Добавлены 3 типа графика (Bar, Pie, Line)
- Добавлены кнопки "Learn more" и "Get started"
- Добавлены логотипы компаний (а точнее их название)

_Комментарий_: Раздел был долгий, пришлось сначала работать с библиотекой [react-charts](https://www.npmjs.com/package/react-charts), но документация очень плохая, да и популярность не такая, как у библиотеки [recharts](https://www.npmjs.com/package/recharts). Ранее я уже работал с [recharts](https://www.npmjs.com/package/recharts), захотел попробовать что-то новое 😄. Но как говорится - "_старый друг, лучше новых двух_".
Также достаточно времени заняло представление размеров на предоставленном макете, т.к. через chrome devtools есть кастомные девайсы, их их представление mobile-horizontal явно расходилось с макетом mobile-horizontal. В проекте подобрано наиболее подходящяя стилизация, но есть небольшие расхождения с макетом.

`Затраченное время: ~ 10 часов`

### 4. Добавление раздела Take action

- Создан компонент карточки для дальнейшего переиспользования в других разделах
- Исправлен градиент в тайтлах. Ранее градиент был на весь текст, что приводило к несоотвутствию с макетом, если текст переносился или имел ширину блока больше чем содержимое
- Также для тайтлов добавлены отзывчивость

_Комментарий_: компонент карты имеет возможность содержать заголовок, подзаголовок, содержимое и иконку. Для возможности переиспользования в других частях проекта и отсутствия переусложнения кода решено было добавить заголовок и подзаголовок, с возможностью добавить либо заголовок, либо подзаголовок, либо и то и другое.

`Затраченное время: ~ 1.5 часа`

### 5. Добавление раздела Real time insights

- В компонент BarChart добавлена возможность передавать label, а также добавлен тип раскрашивания столбцов (каждая секция имеет разный цвет или каждый элемент в секции имеет разные цвета)
- Также для BarChart был написан хук, который имитирует работу медиазапросов и в зависимости от размера экрана возвращает префикс (префиксы и размеры использовались такие же как и в [Tailwind](https://tailwindcss.com/docs/responsive-design)).
- Внесены некоторые изменения в стилизации. В качестве разнообразия приемов в коде введен новый класс с использование Tailwind директивы @apply.

_Комментарий_: немного пришлось для BarChart усложнить логику и написать хук, т.к. другие способы изменять размеры столбцов, расстояния между ними, размер шрифта лейблов не увенчались успехом. В Tailwind конечно есть еще что вынести в отделные классы (например grid-gap). Думал, что с этим разделом будет попроще, т.к. компоненты уже практически готовы. Но recharts не дал соскучиться.

`Затраченное время: ~ 3.5 часа`
