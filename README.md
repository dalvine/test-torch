# Тестовый проект для invest

## Проверка и запуск проекта

```
    npm run prettier
    npm run lint
    npm run build
    npm run start
```

## Этапы разработки

### 1. Подготовка проекта

    - установка Next.js + ts
    - устанвока необходимых для работы зависимостей
    - настройка конфигурационных файлов

_Комментарий_: по тех. заданию был установлен Next.js, модуль tailwaind. Для строгой типизации Next.js был установлен с поддержкой type-script. Для style guide установлены и настроены eslint, prettier.

`Затраченное время: ~ 1 час`

### 2. Добавление Header

    - Добавлен логотип
    - Добавлено навигационное меню
    - Добавлены кнопки "Signin" и "Get started"

_Комментарий_: по тех. заданию проект должен быть с отзывчивым дизайном (адаптироваться под размер). Во всем проекте используется подход desktop to mobile. Логотип был вырезан с макета, т.к. обычно логотип предоставляется. Не стал его делать с прозрачным фоном через фотошоп. Надеюсь это не критично. Остальные логотипы для соответствия макету также вырежу из макета.

`Затраченное время: ~ 2.5 часа`
